# 同步
这块是重点，我踩了很多坑

## 本机同步
其实非常简单：
1. 选择窗口栏 `工具`
2. `选项`，侧边栏选择  `同步`
3. 在同步中选择同步目标为`文件系统`
4. 文件的绝对路径选择一个文件夹，建议选择你创建的**git本地仓库文件夹**。
5. 应用即可

注意事项：
1. 在你需要**更换**同步路径时，必须复制整个同步文件夹到新的路径下，**先**点击同步，再删除原本的文件夹!!!。
2. 严禁关闭同步高级选项里面的故障保护！！（**我永远痛失了我的笔记**）
