# 环境变量

## 主要变量设置
1. `ZEPHYR_TOOLCHAIN_VARIANT`：应该设置为 `zephyr`
2. `ZEPHYR_SDK_INSTALL_DIR`： 应该设置为 你自己安装的zephyr-sdk路径

使用以下命令检查环境变量：
~~~
echo "ZEPHYR_TOOLCHAIN_VARIANT: $ZEPHYR_TOOLCHAIN_VARIANT" && echo "ZEPHYR_SDK_INSTALL_DIR: $ZEPHYR_SDK_INSTALL_DIR"
~~~

使用以下命令设置环境变量：
~~~
export ZEPHYR_TOOLCHAIN_VARIANT=zephyr && export ZEPHYR_SDK_INSTALL_DIR=/opt/zephyr-sdk
~~~

需要说明的是：
- `ZEPHYR_SDK_INSTALL_DIR` 只有在sdk安装在非默认位置时需要设置。
- `ZEPHYR_TOOLCHAIN_VARIANT` 在设置了DIR后就不需要设置了。
