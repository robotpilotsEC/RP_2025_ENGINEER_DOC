# 如何查阅AUTOSAR文档
## 关键词缩写
| 缩写 | 全称（英文）                        | 含义说明（中文）                                  |
|------|-------------------------------------|--------------------------------------------------|
| RS   | Requirement Specification           | 需求规范。一般为整体架构、基础软件或方法论的高层需求。 |
| SRS  | Software Requirement Specification  | 软件需求规范。针对某具体模块或功能的详细需求。        |
| SWS  | Software Specification              | 软件规范。详细说明软件模块的设计和实现。              |
| TR   | Technical Report                    | 技术报告。对某些技术主题进行专项说明或总结。           |
| MOD  | Meta Model                          | 元模型。描述 AUTOSAR 元数据或模型结构。               |
| TPS  | Template Specification              | 模板规范。定义文档或模块的模板结构。                  |
| EXP  | Explanation                         | 说明文档。用于补充说明其他文档中难以理解的部分。       |
