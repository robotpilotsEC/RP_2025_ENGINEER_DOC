# 查看网络地址命令 ip
>ip [ OPTIONS ] OBJECT { COMMAND | help }

- `ip addr`（显示所有网络接口的IP地址信息）  
> ip addr

- `ip a`（简写，显示所有网络接口的IP地址信息）  
> ip a

- `ip link`（显示或操作网络接口）  
> ip link

- `ip link set dev eth0 up`（激活指定接口）  
> ip link set dev eth0 up

- `ip link set dev eth0 down`（禁用指定接口）  
> ip link set dev eth0 down

- `ip route`（显示路由表）  
> ip route

- `ip route add 192.168.1.0/24 via 192.168.1.1`（添加路由）  
> ip route add 192.168.1.0/24 via 192.168.1.1

- `ip route del 192.168.1.0/24`（删除路由）  
> ip route del 192.168.1.0/24

- `ip neigh`（显示邻居/ARP缓存信息）  
> ip neigh

- `ip neigh add 192.168.1.100 lladdr 00:11:22:33:44:55 dev eth0`（添加邻居项）  
> ip neigh add 192.168.1.100 lladdr 00:11:22:33:44:55 dev eth0

- `ip -s link`（显示接口及其数据包统计信息）  
> ip -s link

- `ip link show`（显示所有接口信息）  
> ip link show

- `ip addr add 192.168.1.10/24 dev eth0`（为接口添加IP地址）  
> ip addr add 192.168.1.10/24 dev eth0

- `ip addr del 192.168.1.10/24 dev eth0`（删除接口上的IP地址）  
> ip addr del 192.168.1.10/24 dev eth0

- `ip link set dev eth0 mtu 1400`（设置接口MTU）  
> ip link set dev eth0 mtu 1400

- `ip help`（显示帮助信息）  
> ip help
