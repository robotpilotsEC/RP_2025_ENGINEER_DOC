## 类的构造函数

***

1. 基本知识：构造函数是一种特殊的成员函数，它在对象创建时**自动调用**，用于初始化对象的成员变量。其**名称必须与类名相同**，且没有返回类型

2.构造函数默认没有参数，带参数的构造函数可以灵活的初始化对象
`MyClass(int val) : x(val)`
>x是对象的一个成员


构造函数的执行顺序是：
1. 执行基类的构造函数
2. 执行基类里面的成员对象的构造函数
3. 执行派生类的构造函数

初始化列表：
初始化列表是构造函数的一种**语法糖**，用于在对象创建时直接初始化成员变量，而不是在构造函数体内赋值。这样做不仅更加高效，而且在某些情况下是必须的，比如 `const` 成员变量和引用类型**必须在初始化列表中初始化**

## 拷贝构造函数：
>MyClass(const MyClass &obj) : x(obj.x)

- 将一个对象传递给函数的值参数。

```class MyClass {
public:
    int value;
	
    // 构造函数
    MyClass(int v) : value(v) {
        std::cout << "普通构造函数" << std::endl;
    }

    // 拷贝构造函数
    MyClass(const MyClass& other) : value(other.value) {
        std::cout << "拷贝构造函数" << std::endl;
    }
};

// 以值传递参数，触发拷贝构造
void printObject(MyClass obj) {
    std::cout << "对象的值: " << obj.value << std::endl;
}

int main() {
    MyClass a(42);
    printObject(a); // 这里会调用拷贝构造函数
    return 0;
}
```


- 用一个对象初始化另一个对象。

```#include <iostream>

class MyClass {
public:
    int value;
    MyClass(int v) : value(v) {}
    // 拷贝构造函数
    MyClass(const MyClass& other) : value(other.value) {
        std::cout << "拷贝构造函数被调用" << std::endl;
    }
};

int main() {
    MyClass a(10);         // 普通构造
    MyClass b = a;         // 用a初始化b，调用拷贝构造
    std::cout << "b.value = " << b.value << std::endl;
    return 0;
}
```

## 移动构造函数

```
MyClass(MyClass&& other) noexcept {
        data = other.data;      // 直接“窃取”资源
        other.data = nullptr;   // 原对象指针置空
        std::cout << "移动构造函数" << std::endl;
    }
    ~MyClass() {
        delete data;
    }
```

必须注意的是，这里涉及到了***动态内存管理***，必须写好析构函数
