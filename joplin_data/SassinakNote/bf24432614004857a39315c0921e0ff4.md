# apt包管理器的使用

## 搜索支持的包
~~~
apt search 包名	#可以显示相关的包和其简介
~~~

***
## 安装和卸载
~~~
sudo apt install XXXX
sudo apt remove XXXX

sudo apt-get autoremove
sudo apt-get autoclean  #清除旧版本的依赖
~~~~

~~~
apt list --installed	#列出已经安装的软件包
~~~

***
## 软件包的更新
~~~
sudo apt update		#这个只是罗列可以更新的软件包
sudo apt upgrade	#升级
~~~

~~~
apt list --upgradable	#罗列可升级的软件包和版本号
~~~
