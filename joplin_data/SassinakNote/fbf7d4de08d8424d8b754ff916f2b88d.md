# 如何给文件添加内容
`echo`
~~~
echo "内容" > 文件名    # 覆盖写入
echo "内容" >> 文件名   # 追加写入
~~~
直接在终端上打印
~~~
echo "hello world"
echo 'hello world'
~~~

`cat`
~~~
cat > 文件名
# 然后输入内容，结束时按 Ctrl+D
~~~
