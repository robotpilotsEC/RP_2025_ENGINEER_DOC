# comment 模块
## 简介
这是Kconfig里面的注释语法，于menu很类似，都会在 `.conig` 文件里生成注释并输出到用户界面

*** 
## 示例
~~~
comment "I am a comment"

config MY_CONFIG1
        bool
        prompt "my config1"
~~~
