# 怎么使一个命令在后台运行?
在命令末尾加上 `&` 即可让命令在后台运行。
> sleep 60 &

- 使用 nohup  
`nohup` 命令可以让进程在用户退出终端后继续运行，常与 `&` 一起使用。  
> nohup command &

例如：  
> nohup python myscript.py &
