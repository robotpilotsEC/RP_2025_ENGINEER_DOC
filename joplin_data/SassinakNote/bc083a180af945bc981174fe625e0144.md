# grep命令

- `grep` 的作用  
在文件或文本输出中**查找包含指定字符串的行**，并显示出来。常用于**日志分析**、**文本搜索**与**过滤**。

**参数**
- `-i`（ignore-case）
忽略大小写进行匹配  
> grep -i "error" logfile.txt

- `-v`（invert-match）
显示不包含匹配字符串的行  
> grep -v "test" data.txt

- `-n`（line-number）
显示匹配行并显示行号  
> grep -n "main" source.c

- `-r`（recursive）
递归查找目录下所有文件内容  
> grep -r "TODO" ./src/

- `-l`（files-with-matches）
只显示匹配到的文件名  
> grep -l "import" *.py

- `-c`（count）
只显示每个文件匹配到的行数  
> grep -c "root" /etc/passwd

- `-E`（extended-regexp）
使用扩展正则表达式  
> grep -E "cat|dog" animals.txt

- `-w`（word-regexp）
只匹配整个单词  
> grep -w "main" code.c

- `-A N`（after-context）
显示匹配行及其后 N 行  
> grep -A 2 "error" log.txt

- `-B N`（before-context）
显示匹配行及其前 N 行  
> grep -B 1 "warning" log.txt

- `-C N`（context）
显示匹配行及上下各 N 行  
> grep -C 3 "fail" log.txt

***
使用示例 
忽略大小写、显示行号、只显示不包含字符串的行  
> grep -inv "debug" app.log
