# 项目调试

## 调试工具
openOCD+Cotex-debug插件+SEGGER RTT+daplink
也可以使用jlink来调试，但是目前我还没时间测试
***
### 1. 编写 `launch.json`文件
~~~
"cwd": "${workspaceRoot}",
"executable": "./build/zephyr/zephyr.elf",
"name": "Debug with OpenOCD",
"request": "launch",
"type": "cortex-debug",
"servertype": "openocd",
"configFiles": [
	"./openocd_rtt.cfg"  # 这个.cfg文件可以使用默认项目dm02/support里面的，我选择自己写
],
"searchDir": [
	"/opt/zephyr-sdk/sysroots/x86_64-pokysdk-linux/usr/share/openocd/scripts" #由于我的sdk安装不是在默认位置，这里只是作参考
],
"runToEntryPoint": "main",
"showDevDebugOutput": "parsed",
"device": "STM32H723",
"svdFile": "${workspaceFolder}/../../breeze/boards/damiao/mc02/support/STM32H723.svd",
"objdumpPath": "/opt/zephyr-sdk/arm-zephyr-eabi/bin/arm-zephyr-eabi-objdump",
"rttConfig": {
"enabled": true,
"address": "auto",
"decoders": [
	{
		"port": 0,
		"type": "console"
	}
]
~~~
**注意**：
- `"searchDir"` 是指示相对路径的参数，在 `.cfg`文件是默认在这个路径下去找 `cmsis-dap.cfg`和 `stm32h7x.cfg`文件


### 2. 修改 `prj.conf`文件
需要在这里指示打印函数的输出位置
>printk() → 控制台后端 → 物理输出接口

~~~
# RTT (Real-Time Transfer) Configuration
CONFIG_USE_SEGGER_RTT=y
CONFIG_RTT_CONSOLE=y
CONFIG_UART_CONSOLE=n

# Optional: Enable RTT logging backend
CONFIG_LOG_BACKEND_RTT=y
CONFIG_LOG_BACKEND_UART=n
~~~

### 3. 在 `openOCD.cfg`中打开RTT
~~~
# 只为CPU目标配置RTT（避免重复配置）
proc configure_rtt_for_cpu {} {
    echo "Configuring RTT for CPU target..."
    
    # 配置RTT事件处理 - 只在CPU目标上配置
    stm32h7x.cpu0 configure -event gdb-attach {
        echo "GDB attached - setting up RTT..."
        setup_rtt
    }
    
    stm32h7x.cpu0 configure -event reset-init {
        echo "Reset-init: Setting up RTT..."
        setup_rtt
    }
}

# 初始化完成后配置RTT
init
after 300 configure_rtt_for_cpu
~~~~
