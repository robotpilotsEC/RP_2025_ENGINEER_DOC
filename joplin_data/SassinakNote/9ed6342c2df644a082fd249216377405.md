# 流和消息缓冲区（stream & message buffers）

## 简介

- Stream Buffer 是FreeRTOS提供的一种轻量级通信机制，主要用于数据流（如字节流）的传送。
- 数据是通过**复制机制**传递，即发送方把数据复制到缓冲区，接收方从缓冲区把数据复制出去。
- 需要注意的是，单对单的传输是安全的。如果有多个读取和写入对象，需要**API函数序列化调用**。
