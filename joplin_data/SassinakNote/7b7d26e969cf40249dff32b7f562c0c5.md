# 丢弃本地修改， 远程仓库直接覆盖

1. cd 到子模块

2. `git reset --hard`   //丢弃本地修改

3. `git clean -fdx`    //删除未追踪的文件


后续只需要回到主仓库就可以正常更新覆盖了
