# auto

## 基本知识：

1. 自动类型推断

2. 局部变量，发生在编译期，不会造成程序的运行效率降低，但是会增加编译期的时间

3. `auto`不是一个类型的声明

4. 使用的是**模板实参推断**，

5. `auto`不会是引用类型，要用`auto&` 

```
std::vector<int> v{1,2,3,4,5,6};
auto pos = v.begin();
auto& element = *pos++;
// auto& element = *pos++的推断等价于如下调用模板的推断
template<typename T>
void deduceElement(T& element);
deduceElement(*pos++);
```

## 注意事项：

- auto通常会忽略顶层const，如果希望推导出的类型具有顶层`const`，必须显示声明
 `const auto`

- 未初始化的`auto`不能用
同一行定义多个变量用`auto`必须是相同类型
`auto`不能作为函数的参数和声明数组
初始化为数组时，`auto`推导的类型是指针，`auto&`推导出为数组
