# GDB服务
在Ubuntu的包管理器中，没有 `arm-none-eabi-gdb`但是有 `gdb-multiarch`注意不是 `gdb`。
- `gdb-multiarch`支持跨平台调试，支持多种架构，为我们调试elf文件提供了支持
- `gdb`只能本地调试当前架构。
***
## 安装
>sudo apt install gdb-multiarch

完成后
>gdb-multiarch --version

## 软连接
由于我们vscode上使用的是 `Cortex-Debug`插件，其默认寻找的调试器名称为 `arm-none-eabi-gdb`,因此我们可以用软链接的方式，让`gdb-multiarch`有第二个名字.

这样的好处是不需要我们在 `launch.json`文件中显示配置`“armToolchainPath”`参数,`gdb-multiarch`可以自动被检测使用

> sudo ln -sf /usr/bin/gdb-multiarch /usr/bin/arm-none-eabi-gdb
> arm-none-eabi-gdb --version

此时应该显示和上文一样的版本号。
