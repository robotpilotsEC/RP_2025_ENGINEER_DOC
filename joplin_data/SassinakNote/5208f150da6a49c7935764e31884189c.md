# 软件定时器（software timers）

## 简介
**软件计时器允许设定未来某个时间执行一个函数**
**计时器执行的函数称为计时器的回调函数**
**计时器启动和执行其回调函数之间的时间称为计时器的周期**
**注意**：
1. 计时器回调函数不能阻塞
2. 必须显示创造软件计时器才能使用
***
## The timer service/daemon task, and the timer command queue
- 定时器不属于内核的一部分
- 当操作定时器时，是操作 `timer command queue`来实现的，并且属于私有不可访问
