# 预处理器

## 前言：
预处理器是一些指令，指示编译器在实际编译之前需要完成的预处理。

- 预处理器不是c++的语句，不需要`;`结尾。
-  预处理器以`#`开头

***
## 常见的几种用法
- 宏
- 参数宏
- 条件编译

##

`#`和`##`运算符

`#`运算符会把参数转换为用引号引起来的字符串
~~~
#include <iostream>
using namespace std;
 
#define MKSTR( x ) #x
 
int main ()
{
    cout << MKSTR(HELLO C++) << endl;
 
    return 0;
}
~~~

编译结果是：
>HELLO C++
