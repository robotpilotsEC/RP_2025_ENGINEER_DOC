# menu 模块

## 简介
`menu` 是一个纯粹的菜单项。`menu` 本身不可配置，只是用来**标记**其内部可能拥有**子配置项**

***
## 示例
~~~
menu "menu learning"

config MENU_SUBITEM1
        bool
        prompt "subitem1"

config MENU_SUBITEM2
        bool
        prompt "subitem2"

config MENU_SUBITEM3
        bool
        prompt "subitem3"

endmenu
~~~

- `menu` 项在`.config`中会将菜单提示语作为注释一并写入

~~~
#
# menu learning
#
CONFIG_MENU_SUBITEM1=y
# CONFIG_MENU_SUBITEM2 is not set
# CONFIG_MENU_SUBITEM3 is not set
~~~
