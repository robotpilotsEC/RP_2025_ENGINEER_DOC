# Kconfig symbol值卡住不更新的问题
## 典型例子
~~~
config FOO
    bool "Foo"

config STACK_SIZE
    hex "Stack size"
    default 0x200 if FOO
    default 0x100
~~~
- 初始配置：`CONFIG_STACK_SIZE`=0x100。
`FOO` 变为 y，`STACK_SIZE` 没变（仍为 0x100）

**原因**
- 有 `prompt` 的 `symbol`：**只要 `config` 文件里有值**，`Kconfig` 就认为这是**用户主动设置**，忽略 `default`

## 解决办法
1. 删去 `prompt`完全交给 `Kconfig`自主推导
~~~
config STACK_SIZE
    hex
    default 0x200 if FOO
    default 0x100
~~~
- 这样用户就失去了配置 `STACK_SIZE`的功能

2. 使用**可选 `prompt`**
~~~
config STACK_SIZE
    hex "Stack size" if !FOO
    default 0x200 if FOO
    default 0x100
~~~

- `FOO` 为 n 时，`STACK_SIZE` 可编辑，默认 0x100
- `FOO` 为 y 时，`STACK_SIZE` 不可编辑，自动为 0x200

3. 再设定一个辅助 `symbol` 由用户自己决定是否需要**强制自定义**
~~~
config CUSTOM_STACK_SIZE
    bool "Use a custom stack size"
    help
      Enable this if you need to use a custom stack size. When disabled, a
      suitable stack size is calculated automatically.

config STACK_SIZE
    hex "Stack size" if CUSTOM_STACK_SIZE
    default 0x200 if FOO
    default 0x100
~~~
