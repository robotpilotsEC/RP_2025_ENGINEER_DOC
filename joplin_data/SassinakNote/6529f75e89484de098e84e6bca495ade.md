# 统计文件内容 wc(word count)
- `wc 文件名`       同时显示行数、单词数和字节数（依次输出）

**参数**
- `-l`     统计行数（lines）
- `-w`     统计单词数（words）
- `-c`     统计字节数（bytes）
- `-m`     统计字符数（characters，适合多字节字符环境）
- `-L`     显示最长行的长度（longest line）
