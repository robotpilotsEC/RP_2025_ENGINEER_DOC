# if 和 depends on模块
## 简介
非常好理解，类似条件编译，根据指定的配置决定本配置是否显示。

***

## 示例
~~~
config MY_CONFIG1
        bool
        prompt "my config1"

config MY_CONFIG2
        bool
        prompt "my config2" if MY_CONFIG1

config MY_CONFIG3
        bool
        prompt "my config3"
　　　　 depends on MY_CONFIG2
~~~

- 此配置项表示当第一个配置项为y时，就可以配置第二个配置项，当第二个配置项为y时，才能够配置第三个配置项
