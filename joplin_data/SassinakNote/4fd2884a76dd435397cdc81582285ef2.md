# choice 模块

## 简介
` choice`是一个单项选择模块，用于子模块的**单选**或**多选**

***
## 示例

~~~
choice 
        bool
        prompt "choice learning"

config CHOICE_ITEM1
        bool
        prompt "choice1"

config CHOICE_ITEM2
        bool
        prompt "choice2"

config CHOICE_ITEM3
        bool
        prompt "choice3"
endchoice
~~~
