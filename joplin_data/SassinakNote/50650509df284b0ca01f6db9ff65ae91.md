# 打开文件有什么命令

- `cat` 一次性显示文件全部内容，适合小文件。注意打开的是文件不是目录
- `more` 分页显示文件内容，适合大文件
- `less` 分页浏览器
- `head` 显示文件开头若干行
>head -n 20 filename # 显示前二十行

- `tail` 显示文件末尾若干行
>tail -n 20 filename # 显示末尾20行
