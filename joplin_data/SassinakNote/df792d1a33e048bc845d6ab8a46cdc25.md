# openOCD
>sudo apt install openocd

**需要注意**：在Ubuntu22.04版本中，`apt`包管理器里面的 `openOCD`版本是0.11.0,这和队里的工具链版本并不一致。而且可能会报 `Error: CMSIS-DAP: SWD not supported`
为了与队内版本一致，需要我们手动安装最新版本的 `openOCD`
***
## 删除旧版本
1.卸载旧版本
>sudo apt-get --purge remove openocd  #卸载软件包
>sudo apt-get autoremove
>sudo apt-get autoclean  #清除旧版本的依赖

2.接下来检查环境变量是否还有 `openocd`
>sudo openocd --version #没有显示就说明清理掉了

## 从官方安装新版本
[openocd](https://openocd.org/pages/getting-openocd.html "官方网站" )
根据官方的教程，你可以通过源码构建，也可以选择二进制包。

这里我为了省事，选择二进制包解压安装。
仓库：[github](https://github.com/xpack-dev-tools/openocd-xpack/releases "非官方二进制包维护版")
![ead52e1fe96b018dcbcc0375dcb0e502.png](:/c27ee86fa7b94446b3a7d55d8b663fe7)
选择 `xpack-openocd-0.12.0-6-linux-x64.tar.gz
`

这里选择类似 `apt`一样的管理方式安装解压，下载的位置在哪都无所谓的
~~~
sudo mkdir -p /opt/openocd  	#在opt目录下创建一个openocd文件夹
sudo tar -xzf (~/下载/xpack-openocd-0.12.0-6-linux-x64.tar.gz) -C /opt/openocd  		#括号内请填写你自己下载好的压缩包的路径，并把括号删去
ls /opt/openocd/xpack-openocd-0.12.0-6/bin/openocd 	#检查一下你刚创建的文件夹下是否有已经解压好的openocd
echo 'export PATH=/opt/openocd/xpack-openocd-0.12.0-6/bin:$PATH' >> ~/.bashrc		#加入到环境变量
source ~/.bashrc	#立即生效环境变量
openocd --version	#检查一下是否有生效，有版本号的输出说明没问题了
~~~

如果要升级和卸载都只需要管理 `/opt/openocd/xpack-openocd-0.12.0-6`目录就好了
