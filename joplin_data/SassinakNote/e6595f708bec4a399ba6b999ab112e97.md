# update 命令
**作用**  
- 更新 manifest 文件中定义的所有活跃项目（或指定项目）。
- 主要流程：
  1. 必要时克隆项目。
  2. 必要时从远程获取项目修订（可自定义 fetch 行为）。
  3. 重置 manifest-rev 分支到当前 manifest 修订版本。
  4. 检出新的 manifest-rev commit（默认为分离 HEAD，也可保留/变基本地分支）。

**常用参数**
- `PROJECT`：指定要操作的项目（名称或路径），默认全部活跃项目。
- `-h, --help`：显示帮助。
- `--stats`：打印性能统计。
- `-f {always,smart}, --fetch {always,smart}`：fetch 行为（always=总是 fetch，smart=本地有则不 fetch，默认 smart）。
- `-o FETCH_OPT, --fetch-opt FETCH_OPT`：传递给 `git fetch` 的额外参数（如 `--depth=1`）。
- `-n, --narrow`：仅 fetch 目标修订，不 fetch tags。
- `-k, --keep-descendants`：如果已检出分支是新 manifest-rev 的后代，则保留当前分支。
- `-r, --rebase`：将当前分支变基到新的 manifest-rev。
- `--name-cache NAME_CACHE`：根据项目名从本地缓存克隆项目。
- `--path-cache PATH_CACHE`：根据相对路径从本地缓存克隆项目。
- `--group-filter FILTER, --gf FILTER`：附加 group 过滤器（可多次）。
- `--submodule-init-config <option>=<value>`：初始化子模块时设置 git 配置（可多次）。

**注意事项**
- 必须先用 `west init` 创建好 workspace 才能用 `west update`。
- 此命令不会修改 manifest 仓库自身内容。
- 绝大多数参数可组合使用以满足各种复杂同步场景。
