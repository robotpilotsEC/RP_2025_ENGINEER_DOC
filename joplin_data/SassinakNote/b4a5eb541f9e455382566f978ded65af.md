# init 命令

West `init` 命令总结：

- 用途：创建一个 west 工作区（`workspace`）。
    
- 两种方式：
    
    1.  **本地仓库（-l）**：基于已有的本地 `manifest` 仓库创建 `workspace`。
    2.  **远程仓库（默认或 -m）**：通过克隆 `manifest` 仓库的 URL 创建 `workspace`（如果不指定，默认用 zephyr 的 `manifest`）。
- 常用参数：
    
    - `-m URL` / `--manifest-url URL` ：指定 manifest 仓库的 URL。
    - `--mr REVISION` / `--manifest-rev REVISION` ：指定分支或 tag。
    - `-l` / `--local` ：使用本地仓库而不是克隆 URL。
    - `-o` / `--clone-opt` ：给 `git clone` 传递额外参数（如 `--depth=1`）。
    - `--mf FILE` / `--manifest-file FILE`：指定 manifest 文件名。
    - `directory` ：目标目录（可选，默认当前目录）。
- 注意事项：
    
    - 部分文件系统（如 Windows NTFS）在有其他程序访问时，重命名/删除临时文件可能失败（比如 VS Code 正在打开目录时）。Linux 大多没这个问题。
    - 如果遇到“Access is denied”问题，可尝试 `--rename-delay` 参数增加重命名等待时间。
