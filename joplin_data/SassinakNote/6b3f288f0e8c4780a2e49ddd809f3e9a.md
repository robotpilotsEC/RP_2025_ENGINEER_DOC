# 压缩与解压 tar

- `tar`命令

参数：
- `-c` (creat)创建新的归档文件
- `-z` (gzip)通过 gzip 压缩
- `-v` (verbose)显示操作过程
- `-f` (file)指定文件名
- `-t` 列出归档内容
- `-x` (extract)解开归档文件
- `-j` (bzip2)通过bzip解压/压缩
- `-J` 通过xz解压/压缩
- `-C` 切换到指定的目录再操作

>tar -czvf archive.tar.gz 文件夹
>tar -xzvf archive.tar.gz #解压
>tar -xzvf archive.tar.gz -C /target/dir # 解压到指定目录
