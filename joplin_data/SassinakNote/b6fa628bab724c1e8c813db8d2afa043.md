# 删除文件 rm
删除文件和目录都可以使用 `rm`命令
> rm file.txt
> rmdir emptyfolder/

**参数**
- `-r` 或 `--recursive`        递归删除目录及其内容（必须用于删除非空目录）
- `-f` 或 `--force`            强制删除，不提示，即使文件不存在也不报错
- `-i`                         每删除一个文件前都进行确认
- `-I`                         在删除多个文件或递归删除时，进行一次确认
- `-v` 或 `--verbose`          显示删除过程中的详细信息
- `--no-preserve-root`         允许递归删除根目录（极度危险！）
- `--preserve-root`            默认保护根目录，不允许递归删除（一般默认开启）
