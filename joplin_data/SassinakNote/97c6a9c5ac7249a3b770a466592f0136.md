# imply语句
## 用途
类似于 `select`，但是不会强制 `symbol` 的值为 y，只是“建议”开启（前提是 `symbol`的依赖已经满足了）

**例子**
~~~
config SOC_FOO
    bool "FOO SoC"
    imply USB_KEYBOARD

config USB_KEYBOARD
    bool "USB keyboard support"
~~~
- 当 `SOC_FOO = y` 时，`Kconfig` 会尝试把 `USB_KEYBOARD` 设为 `y`，但如果 `USB_KEYBOARD` 有其它依赖不满足，则**不会强制为 `y`**。
- 用户依然**可以手动关掉** `USB_KEYBOARD`
