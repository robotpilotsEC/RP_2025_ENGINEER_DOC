# head处于detached状态

遇到这个问题，产生的现象就是*上传了代码到head上，但是实际上并没有合并分支*，导致在GitHub
上并没有你的commit

1. `git status` 查看git状态

2.  `git branch -a` 查看分支信息

3.  `git remote -v` 查看远程git的状态

4. `git checkout XXX` 切换回你想要的分支

5.  `git merge XXXX`  手动合并分支，可以去`.git log`里面查你的分支

6.  `git push origin XXX`
