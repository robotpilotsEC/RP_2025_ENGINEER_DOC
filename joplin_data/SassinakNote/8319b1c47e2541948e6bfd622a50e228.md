# 使用openocd下的rtt

## 依赖
OpenOCD v0.10版本以上，目前队里的版本是 v0.12.6（起码按照我的配置安装的是这个版本）

需要下载SEGGER RTT的源码。
[git仓库版](https://github.com/SEGGERMicro/RTT  "官方推荐")
[官网臃肿版](https://www.segger.com/downloads/jlink "我不推荐，很傻比")
值得注意的是，如果你是从jlink下载的源码，请按照以下方式下载解压
1. 根据**你电脑的架构**(不是单片机)选择版本，大部分都是X86架构，选 `64-bit TGZ Archive`
2. 在 `/opt`或任意一个位置，解压
3. 在你解压路径下找到 `.../JLink_Linux_V862_x86_64/Samples/RTT`这里才是SEGGER RTT 的源码压缩包所在，解压
4. 将头文件和源文件移植到工程内。（写好cmake）
***
## 文档
[openOCD官方文档](https://openocd.org/doc/html/General-Commands.html "非常详细")
从15.6开始看，详细介绍了 `.cfg`文件如何写来启动RTT

***
## 配置示例
~~~
source [find interface/cmsis-dap.cfg]
source [find target/stm32h7x.cfg]
adapter speed 10000

# STM32H723 RTT Configuration
# Memory: DTCM 0x20000000-0x2001FFFF + AXI SRAM 0x24000000-0x2407FFFF

# RTT设置过程
proc setup_rtt {} {
    echo "Setting up RTT for STM32H723..."
    
    # 尝试多个内存区域来查找RTT控制块
    catch {
        rtt setup 0x20000000 0x24080000 "SEGGER RTT"
        rtt start
        rtt server start 9090 0
        rtt polling_interval 100
        echo "RTT started on port 9090"
    }
}

# 只为CPU目标配置RTT（避免重复配置）
proc configure_rtt_for_cpu {} {
    echo "Configuring RTT for CPU target..."
    
    # 配置RTT事件处理 - 只在CPU目标上配置
    stm32h7x.cpu0 configure -event gdb-attach {
        echo "GDB attached - setting up RTT..."
        setup_rtt
    }
    
    stm32h7x.cpu0 configure -event reset-init {
        echo "Reset-init: Setting up RTT..."
        setup_rtt
    }
}

# 初始化完成后配置RTT
init
after 300 configure_rtt_for_cpu
~~~
