# git ignore文件

用于告诉Git哪些文件不需要纳入版本控制

1. `/`开头表示根目录下啊
2. 末尾加 `/`表示目录
3. `*`表示匹配热议字符串， `?`匹配单个字符, `**`匹配多级目录
4. `!`白名单

~~~
# 忽略所有 .log 文件
*.log

# 忽略 node_modules 目录
node_modules/

# 忽略所有 .tmp 结尾的文件
*.tmp

# 忽略 build 目录
build/

# 忽略根目录下的 secret.txt 文件
/secret.txt

# 忽略所有 .DS_Store 文件（macOS下常见）
.DS_Store

# 只忽略项目根目录下的 todo.txt，不忽略子目录中的
/todo.txt

# 忽略所有以“temp”开头的文件夹
temp*/
~~~
