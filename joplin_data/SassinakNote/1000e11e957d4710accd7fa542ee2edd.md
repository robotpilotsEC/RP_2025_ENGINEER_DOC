# 指向类的指针

## 基本知识：
与结构体类似，可以使用一个指针指向一个对象

>// 声明和初始化指向类的指针
    MyClass *ptr = &obj;

***
## 动态分配内存

指向类的对象可以用于动态分配内存和创建类的对象

~~~
#include <iostream>

class MyClass {
public:
    int data;

    void display() {
        std::cout << "Data: " << data << std::endl;
    }
};

int main() {
    // 动态分配内存创建类对象
    MyClass *ptr = new MyClass;
    ptr->data = 42;

    // 通过指针调用成员函数
    ptr->display();

    // 释放动态分配的内存
    delete ptr;

    return 0;
}
~~~
