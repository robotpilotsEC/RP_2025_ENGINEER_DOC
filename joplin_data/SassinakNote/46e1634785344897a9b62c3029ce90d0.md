# 动/静态内存分配

## 动态分配内存
- 动态创建RTOS任务，减少RAM的使用量
- 自动在API内存分配

可以选择最适合应用程序的内存分配方案，无论是安全关键应用程序通常需要的简单性和确定性的 heap_1.c，heap_4.c 用于碎片保护，heap_5.c 将堆拆分为多个 RAM 区域

## 静态分配内存
- 最大RAM占用确定
- 无需关注动态内存分配
