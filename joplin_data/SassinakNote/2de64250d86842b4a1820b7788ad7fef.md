# 左值引用与右值引用

1. 左值引用:
~~~
Int x = 10;
Int& ref = x;
Ref = 20;
~~~

2. 右值引用：
> T&&   常用于转动语义和完美转发

***

**引用和指针有区别:**
1. >Int a =10;
Int *p = &a;

这里p是指针，指向a的地址
因此，如果要修改a的值则需要`*p = 20`;这是一个解引用

而`int&`则可以直接操作变量本身

2. 引用是不可绑定别的变量的，而指针变量则可以随便指向新的地址
