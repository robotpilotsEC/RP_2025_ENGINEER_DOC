# 封装特性

### 封装：
**将数据和操作数据的方法进行有机结合，隐藏对象的属性和实现细节，仅对外公开接口来和对象进行交互。**


在c语言中，数据和方法是分离的
c++里面就是把不需要给外部接口的函数封装到类里面，不会出现c里面的直接访问结构体成员的问题
