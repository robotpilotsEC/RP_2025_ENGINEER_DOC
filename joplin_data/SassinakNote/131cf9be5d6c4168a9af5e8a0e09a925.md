# 函数模板

~~~
template <typename type> ret-type func-name(parameter list)
{
   // 函数的主体
}
~~~

以下是两个模板函数的例子：
1.
~~~
template <typename T>
inline T const& Max (T const& a, T const& b) 
{ 
    return a < b ? b:a; 
}
~~~
在这个例子中`T const&`是函数的返回类型，`Max`是函数名。

2. 
~~~
template <typename T>
T add(T a, T b) {
    return a + b;
}

template int add<>(int, int);  // explicit instantiation
~~~

在这个例子里面，使用了显示的初始化。
。但是实际上，函数模板也可以隐式实例化
