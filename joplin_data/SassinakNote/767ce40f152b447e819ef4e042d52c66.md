# git push报错

1. `git push`报错：
   >Updates were rejected because the tip of your current branch is behind

**说明：** 该报错在`git push`时出现，一句话解释就是你在本地仓库上的修改没有基于远程库最新版本，你的本地仓库版本落后于远程仓库。*（这个报错告诉我们在本地开发的时候，要经常使用`git pull`获取远程分支最新改动，这样才能保证在最终`git push`的时候本地）*

**解决方法**：先pull 再push（强制push的方法  `git push -u origin main -f`）
