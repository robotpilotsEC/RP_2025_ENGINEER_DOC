# Std::initializer_list

## 特点： 统一初始化，防止窄化转换

 
 **初始化类：**

 ~~~

public:
    std::string name;
    int age;
    
    // 构造函数
    Person(const std::string& n, int a) : name(n), age(a) {}
};
Person p1{"John", 30};  // 使用列表初始化

std::vector<int> vec = {1, 2, 3, 4}; // 初始化 vector

struct Point {
    int x, y;
};
