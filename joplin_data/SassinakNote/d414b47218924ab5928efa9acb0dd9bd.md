# 一，修改vscode配置

## 项目配置文件

一个协作的项目可以创建一个 `Profile`文件，这个文件可以自动安装需要的拓展和相关配置。

1.  创建一个配置文件  
    ![eb44f49a7f76881c89e9b668208274ac.png](:/5cd975de8bcf467aa89370a3901ffaad)

- 名字和图标看自己喜欢
- 拓展需要自己选择加入,其实就是去插件商店安装，也可以吧常用的插件配置为全局。

## setting.json文件修改

- 其实在**默认**配置下包含了我们所有下载的插件，可以在默认配置文件配置我们常用的功能

```
    "C_Cpp.inlayHints.parameterNames.enabled": true,
    "C_Cpp.inlayHints.referenceOperator.enabled": true,
    "C_Cpp.doxygen.generatedStyle": "/**",
    "C_Cpp.autocompleteAddParentheses": true,
    "C_Cpp.default.cStandard": "gnu11",
    "C_Cpp.default.cppStandard": "gnu++17",
    "C_Cpp.inlayHints.autoDeclarationTypes.enabled": true,
    "vsicons.dontShowNewVersionMessage": true,
    "explorer.confirmDragAndDrop": false,
    "editor.fontLigatures": true,
    "explorer.confirmDelete": false,
    "C_Cpp.doxygen.generateOnType": false,
    "editor.formatOnPaste": true,
    "editor.formatOnType": true,
    "editor.unfoldOnClickAfterEndOfLine": true,
    "editor.rulers": [
        {
            "column": 100
        }
    ],
```

此外一些额外的功能就可以自己在配置文件加了。

## 必要的支持

1.  c/c++插件

- 这个不用说，可以在 `setting.json`里面设置头文件查找路径为 `cmake tool`

2.  cmake
3.  cortex-debug
4.  nrf 相关的几个插件都是需要的
