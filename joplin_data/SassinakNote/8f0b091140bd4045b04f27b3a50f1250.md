# Optional prompts
- 让 `symbol` 的 `prompt`（配置界面可见性）**变成条件化**，只有**在某条件满足时才让用户可编辑**

**例子**
~~~
config MASK
    hex "Bitmask" if HAS_CONFIGURABLE_MASK
    default 0xFF
~~~
- 当` HAS_CONFIGURABLE_MASK = y `时，`MASK` 可由用户配置，默认值 0xFF。
- 当 `HAS_CONFIGURABLE_MASK = n `时，`MASK` 不可见（不可配置），但 `MASK` 仍然有默认值 0xFF
