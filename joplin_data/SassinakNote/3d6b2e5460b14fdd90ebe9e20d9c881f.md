# ls 的功能
ls是常用的**文件和目录**查看命令
`ls "参数" “文件目录”`
## 可带参数
- `-a` (all)显示所有文件，包括以`.`开头(当前目录)的隐藏文件
>ls -a

- `-l`	(long)以长格式显示详细信息（权限、大小等）
> ls -l

- `-h`	(human-readable)配合`-l`，以人类可读方式显示文件大小
>ls -lh

- `-d`	(directory)仅显示目录本身而不是其内容
>ls -d */

- `-R`	(recursive)递归显示所有子目录
>ls -R #会显示全部文件，建议在比较底层的目录打开，不然太多文件了
  
- `-t`	(time)按修改时间排序，最近的排前面
- >ls -lt

- `-r`	(reverse)反向排序（与默认相反）
>ls -lr

- `-S`	(size)按文件大小排序
>ls -lS

- `-i`	(inode)显示文件的inode号
>ls -li

- `-F`	(file type)在每个文件/目录名后加字符区分类型
>ls -F

- `--color`	彩色显示不同类型文件（部分系统默认开启）
>ls --color=auto
