# bash shell中的hash命令有什么作用？
- **加速命令查找**：当你在 `bash` 中执行一个外部命令（如 `ls`、`grep` 等）时，`bash` 会在` $PATH` 指定的目录中查找该命令的位置。为了加快后续的查找速度，`bash` 会把**已找到的命令路径缓存到哈希表中**。下次再执行同名命令时，直接从哈希表里查找，无需再次遍历 `$PATH`。
- 显示和管理缓存：`hash` 命令可以让你查看、删除或重置这些缓存。
