## menuconfig和guiconfig
`menuconfig` 是一个在终端中运行的基于 `curses` 的接口，而 `guiconfig` 是一个图形配置界面

- **永久更改配置**还是需要手动修改 `zephyr/.config`里面的配置

### 需要运行其中一个接口
1. 构建项目
>west build -b  board

2. 运行其中一个config
>west build -t menuconfig
>west build -t guiconfig
