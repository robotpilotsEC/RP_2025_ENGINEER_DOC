# 多态的关键点

1. 虚函数（`Virtual Functions`）：

- 在基类中声明一个函数为虚函数，使用关键字`virtual`。
- 派生类可以重写（`override`）这个虚函数。
- 调用虚函数时，会根据对象的实际类型来决定调用哪个版本的函数。
 
2. 动态绑定（`Dynamic Binding`）：

- 也称为晚期绑定（`Late Binding`），在运行时确定函数调用的具体实现。
- 需要使用**指向基类的指针**或**引用**来调用虚函数，编译器在运行时根据对象的实际类型来决定调用哪个函数。
  
3. 纯虚函数（`Pure Virtual Functions`）：

- 一个包含纯虚函数的类被称为抽象类（Abstract Class），它**不能被直接实例化**。
- 纯虚函数没有函数体，声明时使用= 0。
- 它**强制**派生类提供具体的实现。


~~~
#include <iostream>
using namespace std;

// 抽象类，包含纯虚函数
class Shape {
public:
    // 纯虚函数，没有函数体，使用=0声明
    virtual double area() const = 0;
    // 可以包含普通成员函数
    void info() const {
        cout << "This is a shape." << endl;
    }
};

// 派生类，必须实现纯虚函数
class Rectangle : public Shape {
public:
    Rectangle(double w, double h) : width(w), height(h) {}
    // 实现纯虚函数
    double area() const override {
        return width * height;
    }
private:
    double width, height;
};

int main() {
    // Shape s; // 错误！抽象类不能实例化

    Rectangle rect(3.0, 4.0);
    rect.info(); // 继承自基类的普通函数
    cout << "Area: " << rect.area() << endl; // 输出: Area: 12

    // 可以用基类指针指向派生类对象
    Shape* ptr = &rect;
    cout << "Area via base pointer: " << ptr->area() << endl; // 输出: Area via base pointer: 12

    return 0;
}
~~~

## 多态的实现机制：

**虚函数表**（V-Table）：
- C++运行时使用虚函数表来实现多态。每个包含虚函数的类都有一个虚函数表，表中存储了**指向类中所有虚函数**的指针。

- 虚函数表是一个指针数组，每个元素都是**虚函数的地址**

- 如果子类**重写**了虚函数，那么虚函数表中对应的指针就会指向子类自己的实现。

- 虚函数指针（V-Ptr）：对象中包含一个指向该类虚函数表的指针。这个对象是个隐藏的指针成员，在被**构造**时初始化

- 当你通过基类指针（或引用）调用虚函数时，实际执行的过程是：
1. 通过对象内部的vptr找到对象实际类型的vtable。
2. 在vtable中查找该虚函数的指针。
3. 跳转到该指针指向的函数实现（基类的还是子类的，取决于实际对象类型）。

~~~
#include <iostream>
using namespace std;

class Base {
public:
    virtual void show() { cout << "Base::show()" << endl; }
};

class Derived : public Base {
public:
    void show() override { cout << "Derived::show()" << endl; }
};

int main() {
    Base* p = new Derived();
    p->show(); // 实际调用的是Derived::show()
    delete p;
    return 0;
}
~~~

***
## 注意事项：

1. 只有通过**基类**的指针或引用调用虚函数时，才会发生多态。
2. 如果直接使用派生类的对象调用函数，那么调用的是派生类中的版本，而不是基类中的版本。
3. 多态性需要运行时类型信息（**RTTI**），这可能会增加程序的开销。
