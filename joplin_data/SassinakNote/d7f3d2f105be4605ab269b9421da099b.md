# 首次创建本地仓库及链接远程仓库

1. 进入Github里创建一个远程仓库

2. 在本地创建一个空的文件夹，用Git Bash打开

3. `git init`     //git本地仓库初始化

(`git clone https://XXXXX 	another-runoob-nam`  //使用这个命令可以有效避免远程**push**的时候出现*refusing to merge unrelated*)

若是第一次建立自己的git仓库
`git config --global user.email"邮箱" `  # 使用自己的邮箱
`git config --global user.name"名字" `   # 自己取一个用户名

4. 将要上传的文件放进本地文件夹

5. `git pull origin main` 	//获取远程库的最新历史以免出现，git push报错：`Updates were rejected because the tip of your current branch is behind`

6 `git add .`	//将本地文件夹添加到git仓库（在`git init`下建立的仓库本质上是和远程仓库独立的）

7 `git commit -m "XXXXX"	`		//将项目提交到Git仓库。-m后面的内容是对此次提交的注释说明，可以自己定义任意内容

8 `git branch -M main`				//上传到main分支

9 `git remote add origin https://XXXXX ` 		//origin后的内容为上面自己创建的GitHub仓库的url地址，本地仓库和远程仓库建立链接

10 `git push -u origin main`			//上传本地项目到远程仓库内(可能需要登录)
