# 硬盘自动挂载

## 前言
安装了双系统之后，win下的硬盘通常无法被ubuntu系统自动挂载，因为文件的格式并不相同，为了解决这个问题，需要我们**手动修改**挂载的文件夹(`fastab`)。按照以下步骤一步一步来
***
## 安装依赖
由于win下是 `ntfs` 系统，因此想要在linux下读取文件需要安装 `ntfs-3g`。一般来说默认会安装
~~~
sudo apt update
sudo apt install ntfs-3g
~~~
***
## 查找分区，确认UUID

### 如何看懂这段输出：
- NAME：设备名称
- MAJ:MIN：主次设备号（一般用不到）
- RM：是否为可移动设备（0 代表不可移动，1 代表可移动）
- SIZE：设备大小
- RO：是否只读（0 代表可读写，1 代表只读）
- TYPE：类型（disk/part/loop等）
- MOUNTPOINTS：挂载点（设备被挂载到的路径）

`loop`是snap的虚拟分区，不必理会

***
## 创建挂载点目录
在一些教程上会推荐挂载在 `/mnt/....`目录下，我觉得不好，因为你的文件管理器会看不见你的硬盘，**不便于可视化操作**（你都用 `desktop`了，还搞 `server`那套就太蠢了）
~~~
sudo mkdir -p /media/用户名/卷名
~~~
- 为了文件管理器能看到，选在挂载在 `/media`下
- 用户名写你自己的
- 卷名是自定义的，你喜欢叫什么都可以，后面会用到

***
## 修改 `/etc/fstab`配置
~~~
sudo nano /etc/fstab
~~~
添加以下内容
~~~
UUID=你的UUID   /media/用户名/卷名   ntfs-3g   defaults,uid=1000,gid=1000   0   0
~~~
这里给出我自己添加的示例：
~~~
UUID=BAA455A6A45565C3 /media/sassinak/win_D ntfs-3g defaults,uid=1000,gid=1000   0 0
UUID=86CEA8FCCEA8E5A1 /media/sassinak/win_C ntfs-3g defaults,uid=1000,gid=1000   0 0 
UUID=E828EA5B28EA2870 /media/sassinak/win_E ntfs-3g defaults,uid=1000,gid=1000   0 0 
UUID=80180FE1180FD4D6 /media/sassinak/win_F ntfs-3g defaults,uid=1000,gid=1000   0 0
~~~

***
## 测试挂载是否成功
~~~
sudo mount -a 	#立刻加载挂载
~~~
如果没有报错说明说明基本成功了

如果报了以下错误
~~~
sassinak@sassinak:~$ sudo mount -a

~~~
说明你这个硬盘已经有挂载点了，需要卸载重新挂载
~~~
sudo umount /....	#umount后写你挂载的路径
~~~
再次检查你的 `/etc/fstab`，没问题后再次挂载即可

最后可以重启电脑
~~~
df -h | grep /media/sassinak/
#或者
lsblk -f
~~~
验证自动挂载是否成功
