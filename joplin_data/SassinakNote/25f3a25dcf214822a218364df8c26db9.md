# Linux操作系统原理——内核初始化1

内核的启动简单流程：
1. 计算机BIOS引导
2. 引导程序找到内核镜像，加载到内核并启动内核
3. 内核初始化设备和驱动程序
4. 内核挂载在**根文件系统**
5. 启动一个名为 `init`程序，设定**ID**为1,用户空间的起点
6. 启动其余的系统进程

***
## 查看启动信息
1. 进程启动和停止
~~~
sudo cat /var/log/boot.log
~~~
2. 系统启动后的信息和错误日志
~~~
sudo cat /var/log/syslog
~~~
3. 内核缓冲区日志信息
~~~
sudo mesg
~~~

## Boot Loaders(Uboot)
引导太复杂，贴篇文章：
[详解Boot Loaders](https://www.cnblogs.com/dongxb/p/14147822.html "深入硬件底层的分析")
以下是提炼的精华：
### 第一阶段
**1. 硬件设备初始化**
- 设置时钟（MPLL）
- 设置分频系数
- 关闭中断，看门🐶
- 启动 `ICACHE`,指令缓存，直接操作硬件
- 关闭 `DCACHE`，`MMU`。`MMU`提供虚拟地址映射功能，`DCACHE`依赖这个功能，如果不关闭，数据就只是写到了 `cache`而没回到 `SDRAM`

**2. 准备RAM空间**
- 在 `lowlevel_init` 设置bank地址
- 设置栈地址指向 `NAND`
- 初始化 `NANDFLASH`
- 复制代码到 `SDRAM`(重定向)

### 第二阶段
**1. 检测内存映射**
**2. 为内核启动设置参数**

### Uboot启动内核
1. 传递 `R1`(CPU的ID，可以在 `arch\arm\include\asm\mach-type.h`查看)给内核
2. `R2`存放内存基址，挂载方式等信息
3. 内核以 `tagged_list`形式传递参数。它由一个 `tag_header` 结构和一个联合（union）组成 `arch\arm\include\asm\setup.h`
