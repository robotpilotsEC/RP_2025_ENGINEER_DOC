# 复制文件 cp
简单的复制文件采用 `cp`命令
>cp file1.txt file2.txt


### 参数
- `-r` (recursive)         递归复制文件夹及其内容（用于复制目录）
- `-i` (interactive)       覆盖前进行确认提示
- `-f` (force)             强制执行，若目标文件已存在则直接覆盖
- `-u` (update)            只复制比目标文件新的文件或目标文件不存在的文件
- `-v` (verbose)           显示详细操作过程
- `-n` (no-clobber)        不覆盖已存在的文件
- `-a` (archive)           归档模式，等同于 -dR --preserve=all，常用于备份
- `-b` (backup)            覆盖前备份目标文件
- `-S SUFFIX` (suffix)     指定备份文件的后缀（与 b 配合使用）
- `-t DIRECTORY` (target-directory)  指定目标目录
- `-T` (no-target-directory)  把目标当作普通文件而非目录
- `-d` (no-dereference)    复制符号链接本身而不是其指向的文件
- `--preserve=ATTR_LIST` (preserve)  保留指定的属性，如mode,ownership,timestamps等
