# 环境变量
按作用域来分：
- **系统变量**：对所有用户生效，用于设置系统环境（`PATH`）
- **用户变量**：用户私有。通过不同的配置文件（`.bashrc`,`.bash_profile`,`.profile`等）

常见的配置文件包括：`arm-none-eabi`,`arm-none-eabi`

***
# 以下列举一些常用的Linux环境变量
1. `PATH`：决定了系统在哪些目录中查找可执行文件。当你输入一个命令时，系统会在PATH中定义的目录中**查找该命令的可执行文件**。

2. `HOME`：指定当前用户的主目录路径。

3. `USER`：当前用户的用户名。

4. `SHELL`：指定当前用户默认使用的shell。

5. `LANG`：指定系统的默认语言。

6.  `LD_LIBRARY_PATH`：指定系统在哪些目录中查找共享库文件。

7. `TERM`：指定当前**终端**的类型。

8. `PS1`：定义命令行提示符的格式。

9. `PS2`：定义多行命令的提示符的格式。

***
# 查看环境变量
查看指定环境变量
~~~
echo $(PATH)
~~~
查看全部环境变量
~~~
printenv
#或者
env
~~~
***
# 添加环境变量
- 添加系统变量
~~~
vim /etc/profile	#用vim编辑器打开全局配置文件
export PATH="/opt/STM/STLinux-2.3/devkit/sh4/bin:$PATH"	#添加文件到PATH的最前面，`:$PATH`保留原本的环境变量不被覆盖
source /etc/profile		#重加载 `/etc/profile`
~~~

- 添加用户变量
~~~
vim /home/(用户名)/.bash_profile			#用vim打开 `.bash.profile`文件，这个文件是用户Bash shell启动时会读取的配置文件
#或
vim ~/.bash_profile	#～表示当前用户主目录
export CLASSPATH=./JAVAHOME/lib;JAVA_HOME/jre/lib
#如果想立刻生效还需要source /home/(用户名)/.bash_profile
~~~

***
# 删除环境变量
- 直接法：很蠢
~~~
export PATH=新的路径（去掉要删除的）
~~~
- 正则表达式
~~~
export PATH=`echo $PATH | sed -e 's/:\/root\/bbb//g'`
# `....`反引号里面的内容优先执行
# echo $PATH表示取PATH内的值。
# sed -e表示执行一个sed脚本
# sed `s/old/new/g`表示用 `new`替换 `old`。/g表示全局
# 在这个示例中 sed -e `s/(:\/root\/bbb)/(空)/g`表示全局下用空替换原本的/root/bbb，实现了删除的效果。
# `\`是转义。因为在正则表达式中 `/`是默认的分隔符，需要用 `\/`来表示字面意义上的 `/`
~~~
