# Kconfig中的默认情况
- `bool` 类型：没有 default，自动默认值为 `n`（未启用）。
- `string` 类型：没有 default，自动默认值为 `""`（空字符串）。
- `int/hex`类型必须显示定义default，如果不定义默认值，会使用空字符串，在**工具兼容可能会出现解析出错**
- 如果一个 `symbol` 在多个地方定义，后面的 default 语句**可以覆盖前面的**,但如果后面是**默认定义**，而之前是**显示定义**一个值，那么后面的定义不会覆盖前面的

**例子**
~~~
config FOO
    bool "foo"
    default n

config FOO
    bool "foo"
    default y    #会覆盖前面的定义,如果是n，则不会
~~~
